# Marketing + web assets

Every character image is rendered from the in-game avatar components
(`client/src/components/avatars/*`) by `tools/assets/export-characters.tsx`:

```
npm run assets                  # Drive + repo web assets
npm run assets -- --out <dir>   # write the marketing files to <dir>/<topic> instead
npm run assets -- --no-repo     # don't touch client/public
```

It uses `react-dom/server` + `@resvg/resvg-js` + `sharp` (root devDependencies) and the
macOS Impact / Courier New system fonts for headlines. Drive folders come from
`~/.claude/skills/project-assets/assetpath.sh OnceALiar marketing <topic>`; each folder
has a README.txt. Marketing PNGs are not committed.

## Google Drive: `My Drive/Dev Assets/OnceALiar/marketing/`

| Folder | Contents |
|---|---|
| `characters/svg/<id>.svg` | standalone SVG, default colour (sky), sticker halo |
| `characters/png/<id>-512.png`, `<id>-1024.png` | transparent PNG |
| `characters/webp/<id>-512.webp` | transparent WebP for the landing page |
| `characters/moods/<id>-<mood>-512.png` | idle / sus / caught / win for the 12 free characters |
| `promo-art/lineup-poster.png` | 2400x1350 "The Lineup" newspaper poster of the free cast |
| `promo-art/sticker-sheet.png` | 2048x2048, all 24 characters as die-cut stickers on halftone yellow |
| `promo-art/og-image.png` | 1200x630 share card: logo + La Chancla, Duck Disguise, Totally a Cow |
| `app-icon/` | red spy mask on yellow: icon-1024 master, 512 / 192 / 180 / 32, maskable-512, icon.svg |

## Repo (served by the app)

`client/public/`: `og-image.png` (palette PNG, ~37 KB, referenced by `og:image` /
`twitter:image` in `client/index.html`), `icon-512.png`, `icon-192.png`,
`apple-touch-icon.png`, `icon-maskable-512.png`, `icon.svg`, `icon-maskable.svg`
(names match `manifest.webmanifest`). All regenerated by `npm run assets`.
